# Answer key

Written before any judge ran. Judges never see this file.

- **What this is:** a benchmark or test of security scanners. Known security problems are hidden in cloud setup code, and it shows which problems each scanner misses.
- **Who it is for:** someone choosing or relying on a security scanner, such as a security, compliance or GRC person. Reading it should also make sense to a non-technical person.
- **Main conclusion:** the scanner reporting the most warnings on a standard test project still missed a stated number of the hidden problems (4 of 10 in this sample).
- **The aha and its reason:** a clean scan doesn't prove much, because scanners miss different things; the grid shows, problem by problem, which scanner caught or missed each, and another scanner caught some of those misses.
- **Next action and where:** read the grid or open a row, or press the red "Try it on your own code" button near the headline.
- **Dominant structure in the text-free image:** a large grid or matrix of rows by columns, with coloured status cells, under a headline area.
